Архітектура системи FineRP
=========================

FineRP — це система управління фінансами та податковою звітністю, розроблена спеціально для фізичних осіб-підприємців (ФОП) в Україні. Система надає комплексні інструменти для обліку доходів, розрахунку податків та формування податкових звітів.

Призначення системи
-----------------

Основними цілями системи FineRP є:

* Спрощення фінансового обліку для ФОП
* Автоматизація розрахунку податків згідно з українським законодавством
* Надання своєчасних нагадувань про терміни сплати податків
* Забезпечення синхронізації з українськими банками для автоматичного обліку транзакцій
* Формування точних податкових звітів, готових до подання в податкові органи

Технологічний стек
-----------------

Бекенд
^^^^^

* **Фреймворк**: Django 5.2 (LTS)
* **Стиль API**: RESTful з використанням Django REST Framework там, де це необхідно
* **Обробка задач**: Celery для фонових та запланованих задач
* **Кешування**: Redis для зберігання сесій та кешу

Фронтенд
^^^^^^^

* **Підхід**: Серверний рендеринг з HTMX для інтерактивності
* **CSS-фреймворк**: Bootstrap 5.2.3
* **Іконки**: FontAwesome 6

База даних
^^^^^^^^

* **СУБД**: PostgreSQL
* **Міграції**: Django ORM міграції
* **Резервне копіювання**: Автоматичні щоденні бекапи

Інфраструктура
^^^^^^^^^^^^

* **Контейнеризація**: Docker та docker-compose
* **Розгортання**: CI/CD конвеєр з GitHub Actions
* **Моніторинг**: Prometheus та Grafana

Структура додатку
---------------

Система FineRP організована у декілька Django-додатків, кожен з яких відповідає за певну бізнес-функціональність:

* **core**: Базова функціональність, управління користувачами та спільні утиліти
* **taxpayers**: Управління профілями ФОП та налаштуваннями
* **banks**: Інтеграція з банківськими рахунками та синхронізація транзакцій
* **finops**: Відстеження та категоризація фінансових операцій
* **currencies**: Курси валют та конвертації
* **income_book**: Управління записами про доходи
* **tax_reports**: Розрахунок податків та формування звітів
* **tasks**: Управління завданнями та нагадуваннями
* **notifications**: Система сповіщень про важливі події

Потік даних
----------

Типовий потік даних у системі проходить такі етапи:

1. Користувач підключає свій банківський рахунок до системи
2. Банківські транзакції автоматично імпортуються через API
3. Система категоризує транзакції та ідентифікує доходи
4. Доходи записуються в книгу доходів
5. Виконуються розрахунки податків на основі групи та ставок ФОП
6. Формуються податкові звіти для перегляду та подання
7. Створюються нагадування про майбутні платежі податків

Безпека системи
-------------

Система впроваджує декілька заходів безпеки:

* Автентифікація та авторизація користувачів
* Шифрування чутливих даних
* HTTPS для всіх комунікацій
* Регулярні оновлення безпеки
* Валідація введених даних та захист від поширених веб-вразливостей
* Журналювання аудиту для критичних операцій

Особливості зберігання даних
--------------------------

* Стандартні автоінкрементні ID Django як первинні ключі для всіх моделей
* Додаткове поле `uid` типу UUID для публічних ідентифікаторів
* Оптимізовані індекси для підвищення продуктивності запитів
* Повна транзакційність операцій з даними для забезпечення їх цілісності

Специфіка реалізації для України
-----------------------------

Система адаптована до українських особливостей:

* Підтримка всіх груп ФОП (1-4)
* Розрахунок єдиного податку, ЄСВ та військового збору
* Формування звітності у форматах, сумісних з українськими податковими системами
* Інтеграція з українськими банками (ПриватБанк, МоноБанк)

  * `Документація API ПриватБанку <https://docs.google.com/document/d/e/2PACX-1vTtKvGa3P4E-lDqLg3bHRF6Wi9S7GIjSMFEFxII5qQZBGxuTXs25hQNiUU1hMZQhOyx6BNvIZ1bVKSr/pub#kix.uv2xjvz42r8k>`_

* Врахування українського законодавства при обліку доходів та розрахунку податків
