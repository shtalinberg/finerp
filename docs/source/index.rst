FineRP - Система управління фінансами та податковою звітністю для ФОП
=====================================================================

FineRP — це система для управління фінансами та податковою звітністю приватних підприємців (ФОП) в Україні.
FineRP is a system for managing finances and tax reporting of private entrepreneurs in Ukraine.

.. image:: _static/finrep_logo.png
   :alt: FineRP Logo
   :align: center

Можливості системи
-----------------

* Ведення обліку ФОПів (один користувач може мати декілька ФОПів)
* Синхронізація банківських операцій (ПриватБанк, МоноБанк)
* Ведення книги доходів
* Розрахунок податків (єдиний податок, військовий збір, ЄСВ)
* Формування податкових звітів
* Створення нагадувань та відстеження задач
